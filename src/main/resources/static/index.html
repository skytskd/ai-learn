1️⃣ 基础对话

最入门的 AI 调用——发送一条消息，获取回复。

核心代码

// 最简单的调用
String reply = chatClient.prompt()
    .user("你好，请用中文回答")
    .call()
    .content();

// 带 System Prompt（设定角色）
String reply = chatClient.prompt()
    .system("你是一名 Java 架构师，用中文回答")
    .user(userQuestion)
    .call()
    .content();

// 使用 PromptTemplate（变量注入）
PromptTemplate template = new PromptTemplate("你是{role}，解答{difficulty}的{topic}问题：{q}");
template.create(Map.of("role", "面试官", "difficulty", "高级", "topic", "并发", "q", question));
💡 学习要点：System Prompt 的角色设定影响 AI 回复质量；PromptTemplate 比字符串拼接更安全（防止提示词注入）。

2️⃣ 流式输出

返回 Flux<String>，每个元素是一个 Token，实现打字机效果。

核心代码

// 服务层：返回 Token 流
public Flux<String> streamChat(String message) {
    return chatClient.prompt()
        .system("你是一名友好的 AI 助手")
        .user(message)
        .stream()        // stream() 替代 call()
        .content();      // 返回 Flux<String>
}

// 控制器层：包装成 SSE
@GetMapping(value = "/stream", produces = MediaType.TEXT_EVENT_STREAM_VALUE)
public Flux<ServerSentEvent<String>> streamChat(@RequestParam String message) {
    return streamService.streamChat(message)
        .map(chunk -> ServerSentEvent.<String>builder().data(chunk).build())
        .concatWith(Flux.just(ServerSentEvent.<String>builder().data("[DONE]").build()));
}
💡 面试要点：call() 返回完整 String，stream() 返回 Flux；SSE 比 WebSocket 更简单，适合单向推送场景。

3️⃣ 对话记忆

通过 MessageChatMemoryAdvisor 自动注入历史消息，实现多轮对话。

核心代码

// 获取或创建会话记忆
ChatMemory memory = sessionMemoryMap.computeIfAbsent(
    conversationId, id -> new InMemoryChatMemory()
);

// 创建记忆 Advisor
MessageChatMemoryAdvisor advisor = new MessageChatMemoryAdvisor(memory);

// 带记忆的对话
return chatClientBuilder.build()
    .prompt()
    .system("记住用户告诉你的信息")
    .user(userMessage)
    .advisors(advisor)  // 关键：注入 Advisor
    .call()
    .content();
💡 面试要点：历史越长 Token 消耗越大，常用窗口截断策略；生产环境用 Redis 替代 InMemoryChatMemory。

4️⃣ RAG 系统

检索增强生成：先查向量库，再把结果和问题一起发给 LLM。

完整流程

// === 离线阶段：文档加载 ===
@PostConstruct
public void init() {
    // 1. 加载文档
    TextReader reader = new TextReader(resource);
    List<Document> docs = reader.read();

    // 2. 分块（每块 500 Token，重叠 50）
    TokenTextSplitter splitter = new TokenTextSplitter(500, 50, 5, 10000, true);
    List<Document> chunks = splitter.split(docs);

    // 3. 存入向量数据库
    vectorStore.add(chunks);
}

// === 在线阶段：RAG 问答 ===
public String ask(String question, int topK) {
    QuestionAnswerAdvisor advisor = new QuestionAnswerAdvisor(vectorStore,
        SearchRequest.builder().topK(topK).similarityThreshold(0.7).build());

    return chatClientBuilder.build()
        .prompt()
        .system("只根据参考资料回答，资料中没有就说不知道")
        .user(question)
        .advisors(advisor)   // 关键：RAG Advisor
        .call()
        .content();
}
💡 面试要点：分块大小影响检索精度；Top-K 太大浪费 Token，太小丢失信息；混合检索（向量+关键词）效果更好。

5️⃣ AI Agent

让 AI 自主决策并调用外部工具（天气查询、计算器、数据库查询）。

工具定义

@Component
public class WeatherTool {
    @Tool(description = "查询指定城市当前天气。仅支持中国主要城市。")
    public String getWeather(
        @ToolParam(description = "城市名称，如：北京、上海、杭州") String city) {
        // 模拟数据，生产环境接真实 API
        return switch (city) {
            case "北京" -> "北京：晴，8°C ~ 22°C";
            case "杭州" -> "杭州：晴转多云，18°C ~ 25°C";
            default -> "暂无数据";
        };
    }
}

Agent 对话

public String chat(String userMessage) {
    return chatClientBuilder.build()
        .prompt()
        .system("你可以使用工具：WeatherTool、CalculatorTool")
        .user(userMessage)
        .tools(ToolCallbacks.from(weatherTool, calculatorTool))  // 注册工具
        .call()
        .content();  // AI 会自动判断并调用工具
}
💡 面试要点：Tool 的 description 是 AI 选择工具的判断依据，要写清楚"什么时候用"；ReAct 模式 = 思考→行动→观察 循环。
